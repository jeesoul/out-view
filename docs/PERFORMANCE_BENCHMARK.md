# 性能证据与历史说明

旧文档中的网络吞吐、NAT 成功率、跨省延迟及“降低30–50%”没有与当前生产链路对应的完整可复现证据。本文件不继续把它们列为产品指标。

- `BenchmarkSendData` 测量内存批处理，发送回调为空，不是实际网络吞吐。
- `test/nat/run_matrix_test.sh` 按预设规则模拟结果，不建立真实 NAT 矩阵连接。
- `test/performance/weak_network_test.sh` 含估算吞吐和模拟建连时间。
- `tools/webrtc-stats.go` 连接失败会返回示例数据，不能用作生产监控证据。

本次实际回环验收覆盖125秒同一TCP连接空闲、64KiB数据校验以及四连接共5MiB数据往返，不把数据量测试解释为吞吐基准。执行方法与边界见 [开发指南](DEVELOPER_GUIDE.md) 和 [发布总结](../RELEASE_SUMMARY.md)。

后续提交性能结果应包含提交版本、硬件/OS、网络条件、实际命令、原始结果和重复次数，区分内存微基准、进程间传输与公网端到端测试。
